# Agent Memory Skill

This skill provides guidance for using the agent-memory-rs persistent memory system.

## Installation

1. Download `agent-memory.skill`
2. Import into your AI agent configuration
3. The skill will be available as `@agent-memory`

## What This Skill Provides

- When to use `@memory/learn` vs `@memory/search`
- Best practices for memory management
- Importance scoring guidelines
- Tagging strategies
- Workflow patterns
- Configuration options

## Usage

The skill automatically triggers when Claude needs to work with persistent memory.

See SKILL.md for complete documentation.
